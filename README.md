# React Study Checklist

A study checklist application developed as part of my Front-End React learning path at Alura.  
This project is the next step after my first React project, **TechBoard**, and focuses on building a more organized React application while exploring Hooks, state management, componentization, and local data persistence.

---

## 🚀 Project Goals

Throughout this project, I will explore:

* **React Hooks**
  * `useState`
  * `useEffect`
  * `useContext`
* **State Management**
* **Componentization** & Reusable components
* **Controlled Forms**
* **Local Storage**
* **CSS Modules**
* **Conditional Rendering**

---

## 🧩 Working with an Existing Codebase

This project represents my first experience working on a React application that was already partially developed and structured.

Instead of building the application from scratch, I had to read, interpret, and understand existing components and code before implementing new features.

This introduced an important aspect of professional software development: working within an existing codebase and extending it without starting from zero.
